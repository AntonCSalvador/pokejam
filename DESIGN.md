# PokéJam visual direction

The approved reference is a 1990s basketball arcade cabinet. The live game is the primary visual; menus frame the court instead of replacing it with marketing content.

- Deep aubergine stadium, warm maple floor, cream text, Chicago red, Miami gold, mint for active controls.
- Self-hosted Press Start 2P supplies arcade lettering; system sans supplies readable descriptions. Pixel sprites render without smoothing.
- Desktop layout: compact marquee, short invitation and actions, scoreboard/court, four character slots, then control legend. In-match controls recede and the court expands.
- Buttons use strong contrast and square corners, echoing cabinet controls. Ground markers combine team color, player number, and selection ring.
- Main authored motion is basketball: jumps, dribbling, shot arcs, dunk feedback. Reduced motion suppresses screen shake and flashing effects without hiding play.
- Screens below desktop width retain readable controls and a letterboxed court; keyboard gameplay is explicitly required.

Code-first build follows the approved implementation plan. No generated visual comp or altered visual identity was requested. Browser-tool connection was unavailable at build time; record actual visual evidence before claiming visual verification.
